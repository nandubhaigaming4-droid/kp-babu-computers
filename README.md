# K.P. Babu Computers Website

A responsive static website with an interactive PC showcase and exploded-view animation.

## Publish on GitHub Pages
1. Upload all files/folders in this project to your repository.
2. GitHub → Settings → Pages.
3. Source: Deploy from a branch.
4. Branch: main, folder: / (root).
5. Save.

## Before launch
Replace the placeholder shop address, phone, WhatsApp, hours and social links with verified business information.
Replace sample reviews with real reviews or keep them labeled as sample reviews.
